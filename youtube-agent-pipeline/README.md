# YouTube -> Agent pipeline

Turn a YouTube tutorial into a Claude Code **skill**, using two independent
readings of the video and reconciling them, so the skill is built from what the
video actually shows -- not from what a model *thinks* the video probably shows.

Based on "The YouTube to Agent Engine" (Jens Heitmann). Two tools do the reading:
Brad Bonanno's open-source **`/watch`** skill (`github.com/bradautomates/claude-video`)
and Anthropic's official **`skill-creator`** skill.

## The idea in one line

Claude reads the real frames + captions (via `/watch`). Gemini reads the video
server-side (via `scripts/gemini_review.py`). You reconcile the two into
`SPEC.md`, labelling every claim CONFIRMED / SINGLE SOURCE / CONFLICT. Then
`skill-creator` builds the skill from `SPEC.md`. Two readings catch each other's
hallucinations; one reading doesn't.

## What lives here

```
youtube-agent-pipeline/
  scripts/gemini_review.py   Step 6: server-side Gemini reviewer (zero-dependency,
                             stdlib only; sends the YouTube URL as a video part so
                             Gemini fetches it -- nothing is downloaded locally)
  notes/claude-pass.md       Step 5 template: Claude's frame+transcript reading
  notes/gemini-pass.md       Step 6 output (generated by the script; 2 samples)
  notes/question.txt         the one question you most need answered
  SPEC.md                    Step 7 template: the reconciled, labelled spec
  README.md                  this file
```

`gemini_review.py` is validated and ready. The other files are templates you
fill as you run the pipeline. Keep `SPEC.md` and `notes/` inside the finished
skill's folder afterward -- they are the skill's provenance.

## Run it on your Mac (this is where every step works)

> This scaffolding was built in a cloud container where YouTube is network-blocked
> and installs are ephemeral, so the *video passes* and *skill install* must run
> on your Mac. See "Why not in the cloud" below.

### One-time setup

```bash
# 1. Install the watcher (interactive Claude Code, in your terminal)
/plugin marketplace add bradautomates/claude-video
/plugin install watch@claude-video
# On first use /watch offers to install ffmpeg + yt-dlp via Homebrew -- accept.
# If Homebrew is missing, install it from https://brew.sh first, then retry.

# 2. Free Gemini key -> https://aistudio.google.com/apikey
#    Set it for this shell AND persist it in your shell profile:
export GEMINI_API_KEY=YOUR_KEY
echo 'export GEMINI_API_KEY=YOUR_KEY' >> ~/.zshrc     # or ~/.bashrc
#    (shell profile ONLY -- never inside a repo/synced folder)

# 3. skill-creator is already available as a skill; nothing to install.
```

### Per video

```bash
cd youtube-agent-pipeline

# Put your question in notes/question.txt (one line), then:

# STEP 3 (first time only) -- smoke-test /watch on any short public video:
/watch https://www.youtube.com/watch?v=SHORT_VIDEO --no-whisper

# STEP 5 -- Claude's pass. Pick flags to match the video:
#   mostly talking  -> --detail transcript (or just leave default)
#   mostly terminal -> --resolution 1024   (add --start/--end for one section)
/watch <URL> --no-whisper [--detail transcript | --resolution 1024] [--start M:SS --end M:SS]
#   ...then read the frames+captions and WRITE notes/claude-pass.md.
#   Do this BEFORE running Step 6 so Claude doesn't anchor to Gemini.

# STEP 6 -- Gemini's pass (two samples, model auto-discovery + fallback):
python3 scripts/gemini_review.py <URL> [--start M:SS --end M:SS] [--fps 2]
#   default --fps 1 and --samples 2; raise --fps only for fast on-screen typing.
#   Use the SAME window you gave /watch.

# STEP 7 -- reconcile the two into SPEC.md (label CONFIRMED / SINGLE SOURCE /
#   CONFLICT; end with OPEN QUESTIONS). This is a reading+writing step, not a script.

# STEP 8 -- build the skill:
/skill-creator            # hand it SPEC.md; let it interview you; it writes the skill

# STEP 9 -- run the finished skill once against a real input and fix what breaks.
#   A skill built from a spec but never executed is not finished.
```

### The one command to remember

Point the whole pipeline at a new video with:

```bash
cd youtube-agent-pipeline && python3 scripts/gemini_review.py "<NEW_YOUTUBE_URL>"
```

...then do the `/watch` pass, reconcile into `SPEC.md`, and hand it to
`skill-creator`. (The Gemini script is the only non-interactive piece; the rest
are Claude Code skills you invoke in the session.)

## `gemini_review.py` options

| flag | default | when to change it |
|------|---------|-------------------|
| `--fps N` | `1` | raise to `2`+ for fast on-screen typing / rapid terminal output |
| `--samples N` | `2` | keep at 2 -- a claim in both samples is far more trustworthy |
| `--start` / `--end` | full video | you only need one section (`2:05`, `125s` both accepted) |
| `--question` | reads `notes/question.txt` | the one thing you most need answered |
| `--model NAME` | auto-discover | force a single model instead of the fallback chain |

The model fallback chain is **discovered at run time**: the script lists the
flash-tier models your key can actually use and orders them by preference
(`gemini-2.5-flash` -> `-flash-lite` -> `gemini-2.0-flash` -> `-flash-lite` -> ...),
so a model rename degrades gracefully instead of crashing.

## Reading rules (both passes, and the reconcile)

- Report only what is on screen or said. "not shown" beats a guess.
- **Named things** -- commands, tool names, exact strings, paths, error messages,
  config keys/values -- are the reliable part. Capture verbatim.
- **Numbers** -- durations, counts, timestamps -- are decoration. Don't trust them.
- A suspiciously fluent / over-complete line is a re-check candidate: usually
  training-data fill-in, not something observed in the video.

## Why not in the cloud

This folder was scaffolded from a Claude Code **web/cloud** session. That
environment can't run the video half of the pipeline:

- **YouTube is network-blocked** there (proxy 403), and `/watch` needs to
  download the video -- so no frame extraction, no Claude pass.
- `/plugin` and `/watch` are **interactive CLI commands** you type; an agent in a
  headless session can't invoke them.
- Installs (plugin, skill) and shell-profile exports are **ephemeral** -- the
  container is discarded and nothing reaches your Mac. Only the git repo persists.
- Gemini's pass *would* work from the cloud (Google fetches YouTube server-side),
  but a single Gemini-only reading defeats the two-reading design.

So the durable, portable pieces were committed here; the video passes and the
skill install belong on your Mac.

## `--no-whisper`

`/watch` runs with `--no-whisper` throughout: no Whisper / transcription
fallback. If a video with **no caption track** comes up and you decide you need
audio transcription for that one, add Whisper deliberately then -- not by default.
